# Jr Penetration Tester | TryHackMe

A personal learning and documentation repository for the [Jr Penetration Tester learning path](https://tryhackme.com/path/outline/jrpenetrationtester) on TryHackMe.

## About the Pathway

The Jr Penetration Tester path is a hands-on introduction to **offensive cybersecurity and ethical penetration testing**. It builds the technical skills and methodology needed to assess the security of web applications, networks, systems, and Active Directory environments.

The training follows a penetration test from **planning and reconnaissance** through **enumeration, vulnerability identification, exploitation, privilege escalation, and reporting**. It combines foundational concepts, practical tools, guided labs, and realistic challenges.

## What the Pathway Covers

| # | Section | Focus |
|---|---|---|
| 01 | Start Your Cyber Security Journey | Offensive and defensive security fundamentals and research skills |
| 02 | Penetration Testing Foundations | Guided engagements, ethics, attack lifecycles, and testing frameworks |
| 03 | Network Reconnaissance | Passive and active reconnaissance, protocols, and services |
| 04 | Nmap | Host discovery, port scanning, and service enumeration |
| 05 | Web Application Security Fundamentals | Mapping web applications, content discovery, and server weaknesses |
| 06 | Burp Suite | Intercepting, modifying, and testing web traffic |
| 07 | Web Application Vulnerabilities I | SQL injection, XSS, CSRF, SSRF, and IDOR |
| 08 | Web Application Vulnerabilities II | Authentication, sessions, file inclusion, command injection, and API security |
| 09 | Vulnerability Knowledge | Vulnerability research, databases, scanning, and identification |
| 10 | OWASP Top 10 (2025) | Common web application security risks and weaknesses |
| 11 | Password Attacks | Authentication attacks, wordlists, and password cracking concepts |
| 12 | Metasploit and Exploitation | Exploitation workflows, payloads, shells, and post-exploitation |
| 13 | Privilege Escalation | Linux and Windows privilege escalation techniques |
| 14 | Active Directory Security Testing Basics | AD enumeration, authentication, credentials, and lateral movement |
| 15 | Specialized Domains | Wireless, mobile, cloud, LLM, and other security disciplines |
| 16 | Python Scripting Basics | Python fundamentals and security-focused scripts |
| 17 | Pentesting Methodologies and Reporting | Scoping, threat modeling, findings, reporting, and re-testing |
| 18 | Jr Pentester Challenges | Practical challenges bringing the skills together |
